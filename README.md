# uikit-base

The look of a [web-base](https://github.com/arkaitz-dev/web-base) application, decided
once: a colour engine that derives an accessible palette, light and dark, from your brand
colour; a CSS kit whose classes are its contract; and Hiccup components that put those
classes on correct markup. Hand-written CSS always wins over the kit.

Status: in development, unreleased. The sections below are written as each part lands.
